# **App Name**: TimeWise Payroll

## Core Features:

- Clock In/Out: Simple interface for crew members to clock in and out, displaying current status.
- Live Status Dashboard: Admin dashboard displaying real-time clock-in/out status of all crew members.
- Employee Management: Admin interface to add and edit employee details (name, hourly rate, on-time bonus).
- Late Policy Enforcement: Automatically marks late clock-ins (7:01 AM or later) and adjusts pay calculations accordingly.
- Pay Calculation Logic: Calculates total pay based on on-time status, hourly rate, hours worked, and bonus eligibility. A tool to incorporate special parameters or circumstances regarding payment is present for further customization.
- Payroll Report Generation: Generates detailed daily and weekly payroll reports with employee name, date, clock-in/out times, late status, hours worked, and pay details.
- Weekly Summary Totals: Summarizes total hours and pay earned for each employee on a weekly basis (Saturday-Friday).

## Style Guidelines:

- Primary color: Deep navy blue (#2E3192) for professionalism and reliability.
- Background color: Light gray (#F0F2F5) for a clean, neutral backdrop.
- Accent color: Vibrant cyan (#00FFFF) to highlight important actions and late indicators.
- Body and headline font: 'Inter' for a modern, neutral, and readable interface.
- Use clear, minimalist icons to represent actions such as clocking in/out and report generation.
- Ensure a clear separation between the admin and crew member interfaces, focusing on simplicity for the crew member view and comprehensive data presentation for the admin.
- Use subtle animations to provide feedback on user actions, such as clocking in/out confirmations.
